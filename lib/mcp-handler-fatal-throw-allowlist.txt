# scripts/check-mcp-handler-fatal-throw.mjs allowlist (ADR-0242 §Decision scope #4)
#
# Format: `<relative-path> :: <whitespace-collapsed catch clause>` (one per line).
# CONTENT-KEYED (not line-keyed): an entry is matched by the catch clause text
# itself, so it survives line shifts. An entry goes stale only when THAT catch
# body's own code changes — re-review then.
#
# Grandfather baseline per ADR-0242: the ~56 existing MCP handlers that
# `catch (e) { return { success: false, error: sanitizeError(e) } }` for
# unfiltered errors are pre-existing cultural debt. New handlers should let
# fatals propagate (`throw wrapError(e, RufloErrorCode.X)`) so mcp-server.ts
# emits a proper JSON-RPC -32603 error frame instead of a flattened envelope.
#
# Discriminated catches are NOT flagged (e.g. `catch (e) { if (e instanceof
# OptionalModuleNotFound) return {…}; throw e; }`) — they correctly
# distinguish expected vs fatal.
#
# Regenerate after deliberate changes:
#   node scripts/check-mcp-handler-fatal-throw.mjs --update
#
