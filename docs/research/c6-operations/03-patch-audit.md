## The central divergence axis (read first — frames every premise)

C6's surfaces split cleanly by ownership:
- **loop-workers** = the worker/cron FRAMEWORK (5 `hooks_worker-*` tools + 12-trigger registry + the daemon scheduler). Its fork ADR is a **plugin contract** (ADR-0001); the heavy lifting (worker-daemon, RVF-lock, autonomous learning) lives in the v3 corpus (ADR-0181/0202/0218/0243/0277/0284/0290) which C1/C3 own and C4 cross-referenced. C6 owns dispatch/detect/registry/cron mechanics — all PARITY-healthy. The scheduling primitives the commands name (`ScheduleWakeup`/`CronCreate`) are Claude Code harness primitives, not ruflo patches.
- **cost-tracker** = the **densest C6 plugin ADR cluster** (0001 namespace-routing fix, 0002 agent-booster integration, 0003 the v0.4→v0.15 implementation arc). All three are strongly evidence-disciplined (file:line source-verification, measured benches, explicit metric-honesty disclaimers). Fork-ahead-by-construction (upstream's cost-tracker is the same script/skill posture; the fork added the auto-capture + budget + model-outcome learning).
- **observability** = a plugin contract (ADR-0001 namespace-routing fix) + the v3 **ADR-0238 S3** (delete the dead `agentdb_telemetry_*` tools; redirect the observe skills to the 4 stat tools). The S3 premise (telemetry tools permanently dead — bound class has no `getMetrics`/`getSpans`) was DEMONSTRATED; but the redirect introduced an **unverified-replacement** issue (one of the 4 named stat tools, `circuit_status`, is itself broken by a registry-key typo).
- **browser** = the largest hand-port: **upstream ADR-122 (#2041)** "browser beyond SOTA" (8 phases) cherry-picked/hand-ported via INTEGRATION-LEDGER Batch S, plus the fork plugin contract **ADR-0001 (status: Proposed)** session-as-skill architecture, plus the v3 **ADR-0238 S1** (`browser_cookie_use` honesty) + **ADR-0243 F-10-005** (trajectory LRU). The browser session machinery carries upstream's bugs (the trajectory skew) AND a fix the fork failed to inherit (the `rvf create --kind` Issue-#2015 patch).

So the C6 mistake signature is **TWO un-merged/diverged upstream items in the browser hand-port** (the `rvf create` regression + the shared trajectory skew) + **one unverified-replacement** (circuit_status) — distinct from C4's pure doc-drift and C2's necessity-not-re-justified.
