## The central divergence axis (read first — frames every premise)

C5's structure differs sharply from C4. Where C4 was a deliberate fork-AHEAD divergence (MADR, `agentdb index`, graph-integrity gates), **C5 is upstream-mirrored with NO fork-ahead capability.** The three plugins map to upstream byte-parity-or-behind:

1. **aidefence** — the fork's ADRs (ADR-0247 detection/isError envelope, ADR-0250 PII/learn deferral, ADR-0238 Surface 1 wire-or-remove) are **PARITY-preservation + honest-capability-boundary discipline**, not brokenness-repair. Every one explicitly records "upstream byte-parity holds" / "identical to fork" — the fork tracked upstream's aidefence engine and the ADRs govern *honesty* (isError propagation, the unauthenticated-`learn` deferral, the perf-claim framing fix), not divergence. This is the **C2 pattern at its cleanest** (over-demonstrated premises; the only "risk" is shared-with-upstream doc-drift).

2. **security-audit** — markdown thought-template riding the upstream `security` CLI (`scan/cve/threats/audit/secrets/defend`) + the aidefence engine (`defend`) + memory. Its only fork ADR is the per-plugin ADR-0001 contract; the substance traces to ADR-096 (encryption-at-rest, hand-ported) + the aidefence ADRs. No fork-ahead.

3. **federation** — the one structurally-divergent plugin, but **the divergence is a regression of OMISSION (stale-fork), not a wrong-premise patch.** The fork's federation ADRs (ADR-0078a plugin design, ADR-097 budget via hand-port, ADR-104 transport, ADR-0187 *declined* WireGuard, ADR-0265 fork-native QUIC) are demonstrated; but the fork **never hand-ported upstream's ADR-120 midstream-aware-loader** (the graceful dynamic-import that lets the package load without agentic-flow) — ADR-120 is ABSENT from the INTEGRATION-LEDGER. So federation is dead on a fresh install (R1) because the fork froze at the alpha.5 ADR-104 static-import pattern while upstream advanced to alpha.16. **The risk class is C2's *demonstrated-then-but-diverged-since* (the fork fell behind), plus a packaging-hygiene gap (undeclared `agentic-flow` dep).**
