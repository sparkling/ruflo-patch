## Anything portable?

**One commit — 189e14b47 `docs(router): make model-router docs match shipped impl` — is a real doc-honesty fix worth the queen's attention. Verdict HAND-PORT (not PICK).**

Why it matters and why the fork doesn't already have it:

- Upstream and the fork's **own ADR-0306** independently reached the *same*
  conclusion: the model-tier selector is a **lexical heuristic + Thompson/Beta
  bandit**, NOT a Tiny-Dancer/FastGRNN neural router and NOT Q-learning.
- But **ADR-0306 explicitly scoped itself to `docs/USERGUIDE.md:894`** (the
  "Q-learning"→Thompson fix, T3) and the `integration/src/multi-model-router.ts`
  triage (T1, resolved KEEP). It **left the `v3/@claude-flow/cli/src/ruvector/`
  source headers untouched.** Those are exactly the files 189e14b47 fixes.
- The fork's working tree **still carries the stale wording** in all three:
  - `model-router.ts` header: "Intelligent Model Router using Tiny Dancer" /
    "FastGRNN-based routing decisions" — yet the file's **body is already** the
    fork's ADR-0278 Thompson/Beta bandit (`sampleBeta`, `recordOutcome`,
    contextual `Beta(α,β)` priors, `.swarm/model-router-state.json`). So the
    header lies about code the fork itself wrote.
  - `enhanced-model-router.ts`: `private tinyDancerRouter: ModelRouter` (+ 4 use
    sites) — upstream renames to `baseRouter` with a telemetry-schema-stability
    note.
  - `hooks-tools.ts:4627`: `implementation: 'tiny-dancer-neural'` — upstream
    changes to `'heuristic-thompson-bandit'`.
- 189e14b47 is **pure comments + a private-field rename + one telemetry-tag
  string** — zero behavioural delta — and its new wording is *accurate for the
  fork* (the fork's router really is heuristic+bandit). It plugs the exact
  honesty gap ADR-0306 cares about, on the files ADR-0306 missed.

**HAND-PORT, not PICK:** the fork's three target files are **heavily diverged**
from upstream's pre-189 parent (`enhanced-model-router.ts` ~88/115, `model-router.ts`
~169/148, `hooks-tools.ts` ~1554/1352 lines changed), so `cherry-pick -x` would
conflict throughout. Apply the *intent* by hand: rewrite the `model-router.ts`
header to the heuristic+bandit description, rename `tinyDancerRouter`→`baseRouter`
(public `getStats()`/`tinyDancerStats` shape preserved — telemetry stability),
flip the `'tiny-dancer-neural'` tag, and add the ADR-026 note. Optionally fold in
**f08318f2c**'s two `hooks-tools.ts` "Use when …" tool-description clauses
(`hooks_task-completed`, `hooks_intelligence_unified-stats`) — also absent in the
fork — into the same hand-port, since they touch the same file and are equally
low-risk doc honesty.
