## PICK / HAND-PORT details

No PICKs (no commit applies cleanly without fork adaptation). Three HAND-PORTs:

### 1. a6dd4ab3d — wrap the fork's Stop hook in `/bin/bash -c` (FLAGGED: likeliest genuine port)
- **Why**: Windows exit-126 defect. Fork's `plugins/ruflo-core/hooks/hooks.json` Stop hook is the one command still invoked bare:
  `"\"${CLAUDE_PLUGIN_ROOT}/scripts/ruflo-hook.sh\" session-end || true"`. All the fork's other hooks (PostToolUse:Bash, PostToolUse:Write|Edit|MultiEdit, both PreCompact) are already `/bin/bash -c`-wrapped, so this is the lone inconsistency and matches the fork's own established pattern.
- **Target**: `plugins/ruflo-core/hooks/hooks.json` — Stop block only.
- **Port approach**: `"command": "/bin/bash -c '\"${CLAUDE_PLUGIN_ROOT}/scripts/ruflo-hook.sh\" session-end || true'"`.
- **Risk**: minimal (1 line; POSIX-validated upstream; mirrors fork's adjacent hooks). NOTE the upstream commit squashes in an unrelated security feature (#2149 ToolOutputGuardrail) — take ONLY the hooks.json hunk.
- **Caveat**: this hardens the fork's plugin Stop hook but the broader plugin-hook Windows gap (jq/xargs/.sh) remains — see cdd5308d8/19984c206 FLAG. A `/bin/bash` literal still isn't truly Windows-native; full fix is the cjs migration. As an incremental match-the-pattern fix it's still correct and low-risk.

### 2. b8a49cfb8 — configurable statusline cost symbol + hide toggle
- **Why**: clean additive feature the fork lacks; env vars are ALREADY fork-branded (`RUFLO_STATUSLINE_COST_SYMBOL`, `RUFLO_STATUSLINE_HIDE_COST`). Fork hardcodes `$` at `statusline-generator.ts:733-734`.
- **Targets**: `v3/@claude-flow/cli/src/init/statusline-generator.ts` (generator = source of truth) + `.claude/helpers/statusline.cjs` (regenerate after).
- **Port approach**: add to the generated `CONFIG` object: `costSymbol: process.env.RUFLO_STATUSLINE_COST_SYMBOL ?? '$'` and `hideCost: /^(1|true|yes|on)$/i.test(process.env.RUFLO_STATUSLINE_HIDE_COST || '')`; change the cost-render guard to `if (!CONFIG.hideCost && costInfo && costInfo.costUsd > 0)` and emit `CONFIG.costSymbol` in place of the literal `'$'`. Regenerate the committed `statusline.cjs`.
- **Risk**: low (default behavior unchanged when env vars unset; self-inert). Optional follow-up: register the two env vars in any fork-side env-var-precedence audit (the fork doesn't currently have one — see d79f51b74).

### 3. 02aa8ed53 — back up CLAUDE.md before `--force` overwrite (#2208 portion ONLY)
